# Slozhno Sosredotochit'sya

A responsive landing page with light, dark and automatic themes.

I built this project as frontend layout practice. The main work here was responsive layout, CSS Grid, adaptive images and theme switching with vanilla JavaScript.

## Features

- responsive layout for mobile, tablet and desktop;
- light, dark and automatic themes;
- selected theme saved in `localStorage`;
- CSS Grid layout and gallery;
- responsive typography with `clamp()`;
- CSS custom properties for theme values;
- keyboard focus states for interactive controls.

## Tech stack

- HTML
- CSS
- JavaScript
