# Slozhno Sosredotochit'sya

Responsive landing page with light, dark and automatic color themes.

The project focuses on adaptive layout, CSS Grid, responsive images, CSS custom properties and theme switching with vanilla JavaScript.

## Features

- responsive layout for mobile, tablet and desktop;
- light, dark and automatic themes;
- selected theme is saved in `localStorage`;
- CSS Grid-based page structure and gallery;
- responsive typography with `clamp()`;
- CSS custom properties for theme values;
- keyboard focus states and interactive controls.

## Tech stack

- HTML
- CSS
- JavaScript
